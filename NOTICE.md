# Aviso de terceiros

## Duplicati

Este projeto **não é** o Duplicati e **não é** um produto oficial do Duplicati.

A parte `cartorio/` e `marca/` aplica identidade visual e configuração sobre o
[Duplicati](https://duplicati.com), distribuído sob licença MIT.

> Copyright (c) Duplicati Team
> https://github.com/duplicati/duplicati

Nada aqui altera o funcionamento do backup em si: os scripts trocam arquivos de
interface (CSS, JavaScript, ícones e páginas HTML), guardam os originais numa
pasta ao lado e ajustam opções de configuração pela API oficial do programa.

O `DESINSTALAR.bat` devolve o Duplicati ao estado original.

## AlphaVSS

O Duplicati usa [AlphaVSS](https://github.com/alphaleonis/AlphaVSS) para ler
arquivos abertos no Windows (Cópia de Sombra de Volume). Licença MIT.
